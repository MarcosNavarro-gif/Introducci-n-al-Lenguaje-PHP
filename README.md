# Lab 1 - Introducción a PHP 🐘

Primera práctica orientada a conocer los conceptos básicos del lenguaje de programación PHP, realizada por **Marcos Navarro**. En este repositorio se incluyen diferentes ejercicios que permiten poner en práctica el uso de formularios HTML, el procesamiento de información en el servidor, operaciones matemáticas y conversiones de unidades mediante PHP.

## 📋 Descripción

Este laboratorio tiene como objetivo introducir los fundamentos principales de PHP, incluyendo su sintaxis, el uso de variables, el envío de información mediante formularios `POST`, estructuras condicionales y operaciones aritméticas sencillas. Cada archivo con extensión `.php` corresponde a un ejercicio independiente de la práctica.

## 📁 Estructura del repositorio

| Archivo                    | Descripción                                                                                                                                                           |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lab2.php`          | Contiene un formulario donde el usuario puede ingresar dos números y escoger la operación matemática que desea realizar, como sumar, restar, multiplicar o redondear. |
| `lab2calc.php`                 | Se encarga de recibir y procesar los datos enviados desde `lab2.php` para posteriormente mostrar el resultado de la operación seleccionada.                    |
| `formulario.php`                 | Ejercicio relacionado con el cálculo o la presentación de la edad utilizando información proporcionada por el usuario.                                                |
| `formulario2.php`              | Página adicional utilizada como parte del ejercicio de formulario.                                                                                               |
| `Verificacion de php.php`            | Corresponde al primer ejercicio desarrollado para poner en práctica los conocimientos básicos de PHP.                                                                 |
| `embebido.php`            | Segundo ejercicio enfocado en el uso de elementos fundamentales del lenguaje PHP.                                                                                     |
| `practica1.php`            | Tercer ejercicio de la práctica, destinado a reforzar los conceptos aprendidos.                                                                                       |
| `opearitmetica.php`            | Ejercicio realizado como parte del laboratorio de introducción a PHP con operaciones matematicas.                                                                                          |
| `lab1(area, perimetro).php / lab1(area, perimetro)2`              | Implementación del ejercicio sobre el area y perimetro de un circulo.                                                          |
| `lab1pulgadas.php` / `lab1pulgadas2.php` | Archivos utilizados para realizar conversiones relacionadas con unidades de medida, principalmente pulgadas.                                                          |
| `lab1estilo.css / lab1pulg-estilo.css`             | Archivos CSS encargados de aplicar los estilos utilizados en las páginas relacionadas con la conversión de pulgadas y area y perimetro de un circulo.                                                    |

## 🛠️ Tecnologías utilizadas

* **PHP:** utilizado para desarrollar la lógica y procesar la información en el servidor.
* **HTML:** empleado para crear la estructura de las páginas y los formularios.
* **CSS:** utilizado para mejorar la presentación visual de las páginas.

## 📌 Requisitos

Para ejecutar correctamente los ejercicios se necesita:

* **PHP 7.4 o una versión superior.**
* Un servidor local como **XAMPP, WAMP o MAMP**
