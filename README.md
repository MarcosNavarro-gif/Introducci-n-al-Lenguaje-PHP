# 🐘 Lab 1 - Introducción a PHP

Práctica introductoria al lenguaje de programación **PHP**, realizada por **Marcos Navarro**.

En este repositorio se presentan diferentes ejercicios enfocados en el aprendizaje de los fundamentos de PHP, incluyendo formularios HTML, procesamiento de datos, operaciones matemáticas y conversiones de unidades.

## 📋 Descripción

El objetivo de este laboratorio es poner en práctica conceptos básicos del lenguaje **PHP**, tales como:

* Sintaxis básica de PHP.
* Uso de variables.
* Formularios HTML.
* Envío de información mediante `POST`.
* Procesamiento de datos en el servidor.
* Estructuras condicionales.
* Operaciones matemáticas.
* Conversión de unidades.
* Uso de CSS para mejorar la presentación de las páginas.

Cada ejercicio permite reforzar diferentes conceptos vistos durante la introducción al lenguaje.

## 📁 Estructura del repositorio

| Archivo                                                | Descripción                                                                                                                     |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `lab2.php`                                             | Formulario que permite ingresar dos números y seleccionar una operación matemática como suma, resta, multiplicación o redondeo. |
| `lab2calc.php`                                         | Recibe y procesa los datos enviados desde `lab2.php` y muestra el resultado de la operación seleccionada.                       |
| `formulario.php`                                       | Ejercicio relacionado con el cálculo o presentación de la edad utilizando información proporcionada por el usuario.             |
| `formulario2.php`                                      | Página adicional utilizada como parte del ejercicio de formularios.                                                             |
| `practica1.php`                                        | Primer ejercicio desarrollado para practicar los conceptos básicos de PHP.                                                      |
| `Verificacion de php.php`                              | Ejercicio enfocado en la verificación y uso de elementos fundamentales de PHP.                                                  |
| `embebido.php`                                         | Ejercicio destinado a reforzar el uso de PHP embebido dentro de HTML.                                                           |
| `opearitmetica.php`                                    | Ejercicio relacionado con la realización de operaciones matemáticas mediante PHP.                                               |
| `lab1(area, perimetro).php` / `lab1(area, perimetro)2` | Ejercicios relacionados con el cálculo del área y perímetro de un círculo.                                                      |
| `lab1pulgadas.php` / `lab1pulgadas2.php`               | Archivos utilizados para realizar conversiones de pulgadas a otras unidades de medida.                                          |
| `lab1estilo.css` / `lab1pulg-estilo.css`               | Archivos CSS utilizados para mejorar el diseño y presentación de las páginas web.                                               |

## 🛠️ Tecnologías utilizadas

### PHP 🐘

Utilizado para desarrollar la lógica de los ejercicios y procesar la información enviada por los formularios.

### HTML 🌐

Utilizado para crear la estructura de las páginas web y los formularios de entrada de datos.

### CSS 🎨

Utilizado para agregar estilos y mejorar la presentación visual de las páginas.

## 💻 Requisitos

Para ejecutar los ejercicios correctamente se necesita:

* **PHP 7.4 o superior**
* Un servidor web local, como:

  * **XAMPP**
  * **WAMP**
  * **MAMP**
* Un navegador web.
* Un editor de código, como **Visual Studio Code**.

## 📚 Objetivo del laboratorio

Este laboratorio busca desarrollar una base inicial en PHP mediante ejercicios sencillos y prácticos. A través de ellos se trabaja la interacción entre **HTML y PHP**, el procesamiento de información introducida por el usuario y la realización de operaciones desde el servidor.
